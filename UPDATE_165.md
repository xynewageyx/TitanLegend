# Update 165 – Ein Tank pro Team

- Pro Viererteam ist höchstens eine aktive Tankrolle erlaubt.
- Beim Rollenwechsel zu Tank wird eine bisherige Tankrolle auf DD (oder eine andere erlaubte Nicht-Tankrolle) umgestellt.
- Ältere gespeicherte Teamrollen mit mehreren Tanks werden beim Laden automatisch bereinigt.
- Klassenwechsel können keine zweite Tankrolle erzeugen.
- Schadensabfangen wird ausschließlich vom aktiven, lebenden Tank mit aktivem Schutzskill ausgeführt.
- Keine HP-Regeneration und keine Wiederbelebung hinzugefügt.

Hinweis: Der Rollenwechsel auf Tank tauscht den bisherigen Tank automatisch auf DD; dies ist eine bewusste Bedienentscheidung. Godot/Android-Laufzeittest ausstehend.
