# Titan Legends – Blender Grasland
This pipeline generates an original, procedural, stylized 3D grassland mesh as a GLB for Godot. It is a geometry prototype, not a finished Ulala-quality scene.
Run **Actions → Generate Grasland 3D GLB → Run workflow**. Download the artifact and extract `grasland.glb` into the Godot project (e.g. `res://assets/worlds/grasland/`). Import or instantiate the GLB scene in Godot. The pipeline does not automatically replace `main.tscn` or ship an APK.
All shapes are authored from scratch in Blender Python, with no third-party assets or paid API.
