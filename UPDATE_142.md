# Update 142 – Lesbare Schadenszahlen auf Android

- Gleichzeitige Schadenszahlen werden auf fünf seitliche Spuren verteilt.
- Animation beginnt verzögert, nachdem die globale Position gesetzt wurde.
- Bei mehr als zehn nahen Anzeigen werden zusätzliche normale Trefferzahlen unterdrückt; kritische Treffer bleiben sichtbar.
- Keine Änderung an Schaden, Heilung, Cooldowns oder Bossregeln.
